# BETA — исходники и автоматическая проверка

Сохранены без изменений: Liquid v40 (app/liquid.html), Signature Catalog v2 (app/player.html) и утверждённый стандарт дизайна (design/approved.html). Это пока два независимых прототипа, а не объединённое приложение.

## Автоматизация

GitHub Actions выполняет семь тестов Playwright на Chromium при push, pull request и ручном запуске. Используется мобильный viewport 393×852; для Liquid — программный WebGL. Скриншоты и сообщения об ошибках сохраняются как артефакт QA. Внешние сетевые запросы блокируются в тестах; ответы Audius имитируются для воспроизводимости. Это не проверка живого Audius или реального FPS телефона. Импорт WAV проверяет настоящее локальное воспроизведение. Настройки эквалайзера проверяются на уровне интерфейса, не измерением звукового сигнала.

## Запуск на компьютере

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
```

В Linux при необходимости: `python -m playwright install --with-deps chromium`.

## GitHub

Создай приватный репозиторий BETA, загрузить нужно всё содержимое этой папки, включая `.github/workflows/beta-qa.yml`. В Actions появится BETA QA. При необходимости включи Actions в настройках репозитория, не подключая платные ресурсы. Следи за лимитом минут бесплатного плана; время одного запуска ограничено восемью минутами. Никакой публикации приложения, секретов, платной инфраструктуры или внешних музыкальных запросов workflow не выполняет.

## Ограничения

Синтаксис исходников и тестов проверен локально. Браузерный запуск в среде подготовки блокирует навигацию (ERR_BLOCKED_BY_ADMINISTRATOR), поэтому результат семи тестов ещё неизвестен. После первого CI-прогона устраняются реальные ошибки; оригинальный Liquid остаётся эталоном. Проверка плавности, физики капель, точности отражений, сохранения выбора при смене настроения и полноценного внешнего аудио требует дополнительных тестов и настоящего устройства.
